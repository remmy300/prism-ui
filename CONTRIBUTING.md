# Contributing to Prism UI
Thanks for helping! 
1. Fork and clone, create a branch (`feat/tooltip-arrow`).
2. Edit files in `src/`, then run `npm run sync-docs` and `npm run check`.
3. Add or update the demo in `docs/index.html` for any component change.
4. Keep components zero-dependency, token-driven (no hard-coded colors) and accessible (keyboard + ARIA).
5. Use clear commit messages (`feat:`, `fix:`, `docs:`) and open a PR using the template.

Look for issues labelled `good first issue` and `help wanted`. Questions are welcome in issues.
